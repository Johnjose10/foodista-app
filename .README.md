- HTML
- CSS
- JavaScript
- Docker
- Nginx
- Jenkins
- SonarQube
- Kubernetes

- Docker Hub

## Run Locally

Open index.html in your browser.

Alternatively:

python3 -m http.server 8000

Open:
http://localhost:8000

## Docker Build

Build Docker image:

docker build -t docker777john/foodista:latest .

Run Docker container:

docker run -d -p 8080:80 --name foodista docker777john/foodista:latest

Open:
http://localhost:8080

Check container:

docker ps

Stop container:

docker stop foodista

Remove container:

docker rm foodista

## Push Docker Image

Login:

docker login

Push image:

docker push docker777john/foodista:latest

## Jenkins CI/CD Pipeline

The Jenkins pipeline contains four stages:

1. Checkout Source Code
2. SonarQube Analysis
3. Build and Push Docker Image
4. Update Kubernetes Manifest Repository

### Jenkins Credentials

Configure the following credentials in Jenkins:

Docker Hub:
docker-cred

GitHub:
github-cred

SonarQube Server:
sonarqube-env

Sonar Scanner:
sonar-scanner

Update the manifest repository URL in Jenkinsfile before running.

## Kubernetes Deployment

Create namespace:

kubectl create namespace production

Apply deployment:

kubectl apply -f manifests/deployment.yaml

Apply service:

kubectl apply -f manifests/service.yaml

Check pods:

kubectl get pods -n production

Check deployment:

kubectl get deployments -n production

Check service:

kubectl get svc -n production

## Access Application

Open:

http://NODE-IP:30080

For Minikube:

minikube service foodista-service -n production

## Argo CD

Argo CD monitors the GitHub manifest repository.

When Jenkins updates the Docker image tag in deployment.yaml, Argo CD detects the Git change and synchronizes the Kubernetes deployment.
